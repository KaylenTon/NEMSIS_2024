This is the GitHub repository for **Dr. Hagen's BDA Lab NEMSIS Project (2026).** This repository is currently active. Learn more about [NEMSIS](https://nemsis.org/what-is-nemsis/) here. Data used in this project comes from NEMSIS SAS files and have been imported in R as DataFrames.  

# Get Started
1. Always begin by creating a branch and pulling from master. Do **not** work directly on the master branch. <br />
2. Click "initialData.RData" to import the sampled PcrKeys and list of variables. Learn more about NEMSIS variables [here](https://nemsis.org/media/nemsis_v3/release-3.5.0/DataDictionary/PDFHTML/EMSDEMSTATE/index.html). <br />
3. In "data_cleaning_2.0.R", run all lines after 134. <br />
<br />
Now, you will have the cleaned NEMSIS DataFrame to begin data analysis.<br />

# How To Contribute
Active tasks are listed in the [Weekly BDA Lab Meeting Reports](https://docs.google.com/document/d/1E0b-f79rgm5o-a6QD39xAG8AQNlWlJybrNJhgVnpjms/edit?usp=sharing) tab. To work on an task, please join the [BDA Lab Discord server](https://discord.gg/qYFpRFpdka) and contact Natalia. Tasks may or may not be programming-related. <br />
1. To work on task, create a separate branch with the title: "taskname-yourname" <br />
2. Pull from master in the RStudio IDE and change to your branch. <br />
3. As you work, remember to pull/rebase your branch regularly. <br />
4. When you're done making changes, make a [pull request](https://github.com/KaylenTon/NEMSIS_2024/pulls). This can also be done on the same page of your branch. <br />
5. Once your pull request has been reviewed and approved, you may merge your file to master. Close the original issue. <br />

# Status of Project
As of 6/14/26, this project is in the **exploratory phase.** We are not conducting statistical tests until we gather more information surrounding NEMSIS. As such, we are prioritizing literature reviews and scatterplots of variable interactions.
